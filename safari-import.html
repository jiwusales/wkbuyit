JIWU 官網訂單匯入

在 iPhone 設定一次，就能從 Safari 的訂單明細頁分享回後台。支援吉伊、白熊、本舖、手遊與リララモード官網。

  1. 開啟 iPhone「捷徑」，按右上角「＋」，命名為 JIWU 官網訂單匯入。
  2. 在捷徑詳細資訊開啟「在分享表單中顯示」，接收類型只保留 Safari 網頁。
  3. 新增 在網頁上執行 JavaScript，輸入選「捷徑輸入」。清除預設程式碼，再貼上下方複製的完整程式碼。
  4. 新增 打開 URL，輸入選擇上一個動作的 JavaScript 結果，儲存捷徑。

若捷徑提示不允許執行腳本，請依提示到「設定 → App → 捷徑 → 進階」開啟「允許執行腳本」。這是 Apple 執行網頁 JavaScript 的必要設定。

每次下單後

在 Safari 登入官網並開啟該筆訂單明細 → 分享 → JIWU 官網訂單匯入。回到後台登入後，確認商品名稱與數量，再按 SAVE。

重複的訂單會被攔下。加入官網購物車不會先登記成已訂購；小幫手以儲存後的實際訂單統計數量。

捷徑僅讀取目前訂單頁的商品與訂單資料，不讀取密碼或 Cookie，也不回傳收件地址。若官網更改版面而無法完整辨識，會停止匯入並顯示原因。
